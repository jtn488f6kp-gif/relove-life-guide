# 发布操作手册

仓库内容已全部就绪，只差账号和推送。按顺序执行：

## 第 1 步 · 你来做：注册账号并建仓库（约 5 分钟）

1. 打开 github.com → Sign up，用户名建议与书相关、不挂真名（如 `relove-guide`）
2. 登录后点右上角 **+** → **New repository**
3. 填写：
   - Repository name: `relove-life-guide`（或你喜欢的名字，与目录名一致最好）
   - 可见性: **Public**
   - **不要**勾选 "Add a README"（我们本地已有）
4. 点 Create repository，**复制页面上给出的仓库地址**（形如 `https://github.com/你的用户名/relove-life-guide.git`）

## 第 2 步 · 你来做：让本机能推送（二选一）

**方案 A（推荐，最省事）——HTTPS + Personal Access Token**
1. GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)** → Generate new token
2. 勾选 `repo` 权限，有效期给 90 天
3. 把 token 发我，或在下面第 3 步命令里替换 `<TOKEN>`

**方案 B——SSH**
1. 终端运行 `ssh-keygen -t ed25519 -C "relove"`，一路回车
2. `cat ~/.ssh/id_ed25519.pub`，复制输出
3. GitHub → Settings → SSH and GPG keys → New SSH key → 粘贴

## 第 3 步 · 我来做：推送上线

你把仓库地址（和 token）给我之后，我执行：

```bash
cd relove-life-guide
git init && git add -A && git commit -m "v2.1: initial release"
git branch -M main
git remote add origin <你的仓库地址>
git push -u origin main
```

## 第 4 步 · 你来做：开通在线阅读（1 分钟）

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. Source 选 **Deploy from a branch**，Branch 选 **main / (root)**，Save
3. 一分钟后，`https://你的用户名.github.io/relove-life-guide/` 即可访问
