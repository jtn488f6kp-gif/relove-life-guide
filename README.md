# 重新爱上生活指南

> 生活不是等风险清零之后才开始。这本书只处理一件事：当日子已经能过下去，怎么让它重新值得过。

一本开源的中文生活重建指南。不解决风险，也不解决成败——它用**一组小剂量、可重复、能被自己看见的动作**，帮你重建四样东西：

- **可预测感**（我知道明天大概会怎样）
- **掌控感**（我做的事有可见的结果）
- **联结感**（有人知道我今天在）
- **可期待感**（有件事我等着它发生）

## 体例

每条按"遇到的情况 — 判断关键 — 先做什么 — 可以怎么说 — 花掉什么 — 可能换回什么 — 关键数字 — 例外与代价"展开。有数据的标注证据等级（A：多项 RCT 或高质量元分析；B：队列研究或方向一致的中等质量证据；C：单项研究或合理推论），没有数据的明确标注"经验建议"。
